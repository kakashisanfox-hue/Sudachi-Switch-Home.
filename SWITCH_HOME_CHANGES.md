# Sudachi Switch Home - v0.1 prototype

Changed GamesFragment.kt to show the existing game cards in a horizontally scrolling list instead of an adaptive grid. The existing GameAdapter, launch behavior, and native emulator code remain unchanged.

This is a first source-code modification, NOT a finished Nintendo Switch HOME interface. Card sizes are unchanged and may need layout adjustments. Build has not been tested. Original GPL-2.0-or-later license and notices must be retained.
