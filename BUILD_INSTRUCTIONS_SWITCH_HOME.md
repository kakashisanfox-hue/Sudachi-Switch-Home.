# Sudachi Switch Home 0.3

1. Envie o conteúdo da pasta `Sudachi-main` para a raiz de um repositório GitHub.
2. Abra Actions > Build Sudachi Switch Home Android > Run workflow.
3. Se o build concluir, baixe o artifact `sudachi-switch-home-build-output`.

ATENÇÃO: workflow experimental, não validado. O repositório ZIP não inclui os submódulos; o workflow clona o upstream para recuperá-los. O upstream ou dependências podem estar indisponíveis, e mudanças de versão podem impedir a aplicação das modificações. Não inclui firmware, keys ou jogos.
