# Sudachi Switch Home v0.2 (protótipo)

Modificações na interface Android: lista horizontal, cartões maiores, cabeçalho HOME, rodapé informativo e fundo escuro. O motor de emulação não foi alterado.

## Limitações
- Não é uma réplica completa da HOME do Nintendo Switch.
- O rodapé é informativo, não são botões funcionais.
- Não foi compilado nem testado em dispositivo.
- Build Android exige SDK, NDK, CMake e dependências nativas do repositório; não foi incluído workflow que prometa build sem validação.
- Respeitar licença GPL-2.0-or-later e avisos de terceiros ao distribuir.
